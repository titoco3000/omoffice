# 10 - Meeting UX

## mute icon

If a user is muted, there should be an icon in the bottom-left corner of their tile. Can we know if a user is muted just via the chime?

## forced controls

The buttons to mute / disable camera of other users should be disabled if they are already muted / with no camera. Also, those buttons are currently inaccessible on mobile; they should appear if the tile has focus within.

## tiles layout

The tiles in the meeting should occupy the full available space. We need an extra control on each: pin. Pinned tiles should occupy most of the space, with all other tiles staying in one single column to the right.

If anny user shares the screen, that becomes the pinned tile immediatly.

## Lock meeting

Lets add the option to lock a meeting. Only users with invites may join it, if not already part of it. In the frontend, a padlock icon button locks/unlocks a current meeting.

Routes will need to be created in the backend. The meetings list in OrgOnlineView needs to show if a meeting is locked.

## meeting start

Lets simplify the controls that appear when we click on a user in the OrgOnlineView. 

we not in meeting, user not in meeting -> "join" (new meeting with force join)

we not in meeting, user in unlocked meeting -> "join" (join meeting)

we not in meeting, user in locked meeting -> "invite" (new meeting + invite)

we in meeting, user not in meeting -> "join" (new meeting with force join), "invite"

we in meeting, user in unlocked meeting -> "join" (join meeting, popup to confirm leaving current meeting), "invite"

we in meeting, user in locked meeting -> "invite"
