# 14 - map meetings

When a user moves, it should check all the cells in a square around him (2 cells to each direction). If there is a user in there, it should join them in a meeting (similar to how the 'join' button currently works). But this joining needs to beware of meetings already happening. 

User A walks by user B: a new meeting is created for them.

User A is in a meeting with B and walks into range of C: C joins their meeting.

User A is in a meeting and walks into range of B, who is also in an active meeting: all users from the meeting with A join B's meeting

User A is in a meeting with B and walks outiside of the range: A leaves the meeting
