# 18 - better map and non-map integration

The app needs to support two modes - with or without the map. 
We need to better integrate the modes.

1. When clicking to join a user in the no-map mode, the avatar should still be moved in the map into the meeting
2. Clicking to leave a meeting should look for close cell with no meetings and move there

# 18.1 - meeting interface during map mode

The camera and mic beeing active or not during meetings should be persistant.

In desktop mode, there should be controls for that in the sidebar, and the user icon should be replaced with the camera preview (if camera active and without a meeting panel).

If in desktop mode and alone in a meeting, the meeting should terminate quicker.

# 18.2 - waves

Implement a 'wave' system. When you click on a user in the users list, you may join or wave at
them. Waves work similar to meeting invites, but dont create a meeting untill the waved user
interacts with the notification. On map mode, the user who answers a wave also walks to you

# 18.3 - notification sounds

Move the file notification.mp3 to some sensible location and play it on incoming notifications.
