# 12 - UI Overhaul

Lets reorganze the frontend.

General principles: tailwind with colors, fonts and general styles set by a single unified theme. Includes dark/light mode.

## Important components

### NavContainer

Used in all pages except for login and the root

* Desktop

Renders a sidebar to the left and the content in the remaining space of the screen.
This sidebar contains, in order:
1. omoffice logo and title -> button to collapse sidebar
2. OrgUserList -> fills available space, scrollable
3. User icon and name-> link to user management
When collapsed, only the icons of each session appear

* Mobile

Renders a botton bar the content in the remaining space of the screen.
This bar contains, in order:
1. User icon -> link to user management
2. omoffice logo
3. either a 'meeting' icon (if meeting active and not on meeting page) or a list icon (link to /users page)

### OrgUserList

List of active users of the current org and active meetings.
If the available width is too small, only show the users icons (for now, their first letter).
Clicking on a user starts a meeting and invites them. If already on a meeting, each user is a dropdown with two buttons: invite of leave current meeting.
