# 12 - Profile picture

Create the system to allow uploading images to be used as both the organization icon and the user icon.

Steps:
1. Add a bucket to hold user-uploaded media.
2. Add a column to the user, organization and user_org tables to hold the picture. Will work like the name - you might have a global profile pic and choose one specific for you inside an org.
3. Add a mechanism to upload avatar pics. The image should be resized to MAX_AVATAR_SIZE x MAX_AVATAR_SIZE on the frontend before upload AND after, on the backend, as a safeguard. Use S3 pre-signed upload links.
4. Create the UI to do so. It should open a panel with a preview of the image, when it is cropped to the correct size, and a button to submit it

# 12.1 API details

We need to update some of the routes. For starters, renaming all /rbac/orgs to /rbac/org.

Then, we need the following routes to be set, replacing previous ones.

GET /rbac/me -> email, name, picture, orgs list (with their id, name, picture)
PUT /rbac/me/name -> Updates name
PUT /rbac/me/picture -> Promotes picture in staging area to profile picture, doing required transformations to it
DELETE /rbac/me/picture -> Removes current pic

GET /rbac/me/org/<org-id> -> name in org (if any), picture in org (if any), roles list

PUT /rbac/me/org/<org-id>/name {name} -> Updates name in org
PUT /rbac/me/org/<org-id>/picture -> Promotes picture in staging area to profile picture within the org, doing required transformations to it
DELETE /rbac/me/org/<org-id>/picture -> Removes current pic

DELETE /rbac/me/org/<org-id> -> Leaves org

GET /rbac/org/<org-id> -> {name, picture}
POST /rbac/org -> create org

PUT /rbac/org/<org_id>/name -> rename org
PUT /rbac/org/<org_id>/picture -> Promotes picture in staging area to org logo, doing required transformations to it
DELETE /rbac/org/<org_id>/picture -> Removes current pic

GET /rbac/org/<org_id>/members -> {members (with their id, name, email, picture, roles, online)}

DELETE /rbac/org/<org_id>/members/<user_id> -> removes user from org

GET /media/upload -> requests upload URL for current user (to staging area)
