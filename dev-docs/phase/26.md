# 26 - admin panel

Lets add a new, secret role - sys-admin. Add a new table that indicates what users are sys-admins. Users that have it should have a button in the profile page to go to /admin. In there, there is a sys-admins table with a form to add new sys-admins (by email, creating user if not there) and buttons to remove sys-admins. There is also a table to list orgs with their user count and online user count. Clicing on an org opens /admin/org/<org-id> and allows seeing the org map in a small canvas, together with the org's own admin user list.

# 26.1 - value compositon graph


Lets create a component ValueCompositionGraph. It receives a list of objects like this:

[{label: "first", composition: {costA: 1.2, costB: 1.3}}, {label: "first", composition: {costB: 12.3, costC: 32}}]

and optionally colors for composition labels:

{costA: 'red'}

It should rank the labels by their average and render them all. Then, to the right of that, a graph bar where each bar is composed of the composition of each value.

From each composition label leaves a connection made up of only horizontal and vertical lines, connecting it to the correspondent section of the first bar. Then, from the section in the first line, to the section in the second, and so on.

On top of each bar, there is the bar label.

Hovering on one of the composition labels makes its text bold and displays the value of the highlighted section on each bar as a number.

This component should be used to display the cost of each org simulation.
