# 8 - Messaging

### Prompt

Create a messager module. It should include two sub modules: one that communicates directly to user browser sessions using websocket and one that send an email, with an easy way of adding more channels in the future (SMS, notifications, etc).

For now, the email should be a stub and just print the message to the console.

Then, just as a test, create a chat system. Every user of the org should receive messages send by every other user. No need to save the messages to the database.
