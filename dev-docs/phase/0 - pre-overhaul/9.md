# 9 - Organization Invites

Create a organization invite and meeting invite system.

Instead of directly adding a user to an org, we are able to send an invite to them.

The invite looks different deppending on if the email is already registered as an user or not.

The email contains a magic link to login and accept.

If the invited instead logs in independently, there is a 'pending invite' session.

If the invited is already logged in when the invite is issued, they receive it via websocket and a toast is displayed.
