# 21 - colision and navigation

We recently added walls. The user should not be able to walk over a wall. To do that, we will need to:

1. Track user direction, so that a user rotating "in place" is still propagated to other users in the org;
2. Prevent move to a wall; instead only rotate the user;
3. Implement a path-finding algorithm to choose the path, instead of relying on always a single horizontal then vertical movement;
4. Implement a "teleport" if the location is unreachable
