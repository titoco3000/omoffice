# 23.3 - Editor

Lets implement a MAP EDITOR. Upon loading, an organization's map should be loaded from a bucket at maps/<org-id>.png. If not there, load the default map.

A user may click on a button on the sidebar (or the users panel in mobile) to ented 'edit mode' if they are in the map. In edit mode, there is a panel with three tabs: floor (base), furniture (mid) and objects (top); and an eraser. Selecting one carries a ghost representation of the object. Clicking or dragging on the map draws a pixel of the object's color code in the correct layer. If any changes exist between the image held in the user's state and the one saved to the server, a 'save' button appears. Saving uses the user staging upload. Upgrading the staged image to the org map resizes it to the correct size (if not already like that), saves it, and sends a channel message to all connected users's frontend to fetch the new map.
