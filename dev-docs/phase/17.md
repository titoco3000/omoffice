# 17 - user sprite

@user-sprite.png I have a spritesheet with nine sprites, each one 32 x 32.

The rows are a user facing down, left and up.
The columns are idle, walk1 and walk2 for that direction.

We need to apply those sprites to each user on the map, as their avatar. What is currently the avatar should be renamed the user-icon, and be shown in the top-right of their avatar.

The avatar should be animated during a walk, cicling between the keyframes: idle -> walk1 -> idle -> walk2 in the correct orientation. Movement to the right should be the same as to the left, but mirrored.

# 17.1 - straight movement

When a user clicks on a tile, their sprite shouldnt be directly translated to their target position: the sprite doesnt look good walking diagonally. Instead, it should trace a deterministic path there, walking vertically and/or horizontally.

# 17.2 - target position

When clicking to move, the position shouldnt be relayed to the backend one step at a time - only the target position should. That way, crossing someone during a path doenst start a meeting, and clicking on someone will start the meeting immediatly, even before the avatar has reached it.

# 17.3 - zoom

Add the ability to zoom in and out the map - from 10 cells wide all the way to the entire map visible at once.
It should work both with the browser zoom commands (ctrl +, pinch, ctrl scroll, etc) and with a +/- buttons to the top right.
