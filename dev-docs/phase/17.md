# 17 - user sprite

@user-sprite.png I have a spritesheet with nine sprites, each one 32 x 32.

The rows are a user facing down, left and up.
The columns are idle, walk1 and walk2 for that direction.

We need to apply those sprites to each user on the map, as their avatar. What is currently the avatar should be renamed the user-icon, and be shown in the top-right of their avatar.

The avatar should be animated during a walk, cicling between the keyframes: idle -> walk1 -> idle -> walk2 in the correct orientation. Movement to the right should be the same as to the left, but mirrored.
