# 7 - UI update

Lets reorganze the frontend.

General principles: tailwind with colors, fonts and general styles set by a single unified theme. Includes dark/light mode.

## Pages

/ homepage, explaining the tool. There is a login button if not authenticated, or an "access my orgs".

/login redirects to /in if already authenticated

/in main page, shows OrgOnlineView, inbox and button to create meeting. If not part of any org, shows "You aren't member of any organization" and a button to go to org creation

/profile Allows changing name, name inside org, switching orgs, button to leave org and link to org creation. If has permissions, shows link to /org

/org Controls to change org name, UsersManagement, delete org

/org/new org creation form


## Meetings

The meetings panel is persistent between pages. In desktop it works as currently, draggable. In mobile mode, it instead toggles between occupying the top half of the window (or right half, if in portrait mode) or fullscreen. Im mobile the toggle button is in the main nav system.


## Important components

<Inbox>

<OrgOnlineView> list of online users grouped by meeting and offline users

<UsersManagement> list of users, their roles, prefered name, email and options to change roles / kick out of org. Also form to add user.

<Meeting> Panel for the current meeting. Displays one tile for each participant, replaced by their camera if they are online. Hovering each tile reveals buttons to mute/disable camera for each. On the bottom right, there is a chat icon. On mobile it toggles between chat view and tiles view; on desktop expands the chat column.

To the bottom left there are the meeting controls: leave, toggle camera, toggle mic, share screen.

When a user's mic is producing sound, their tile's border becomes a different color (see theme).

<NavContainer>

Used in all pages except for login and the root

* Desktop

Renders a sidebar to the left and the content in the remaining space of the screen.
This sidebar contains, in order:
1. omoffice logo and title -> button to collapse sidebar
2. OrgOnlineView -> fills available space, scrollable (not present if in /in)
3. User icon and name-> link to /profile
When collapsed, only the icons of each session appear

* Mobile

Renders a bar to the bottom of the screen (side if device sideways). The content fills in the remaining space of the screen.
This bar contains, in order:
1. User icon -> link to user management
2. omoffice logo. On meeting, doubles as the meeting panel size toggle
3. list icon -> link to /in

The bottom bar

### OrgUserList

List of active users of the current org and active meetings.
If the available width is too small, only show the users icons (for now, their first letter).
Clicking on a user starts a meeting and invites them. If already on a meeting, each user is a dropdown with two buttons: invite of leave current meeting.
