# 21 - map tiles

Take a look at the files I added to assets. You will move them to a more effective place in the frontend. It will be used to draw the map. Each pixel in map.png represents a tile. For now, we have only three tiles: grass (0 255 0), sand (255 255 0) and water (0 0 0 and any other color not asigned). 

# 21.1 - assets

Move all images of frontend/src/features/map to frontend/src/features/map/assets

# 21.1 - transitions

We need to add transitions between the tiles of different types. Organic tiles (like sand or grass) to other organic should blend into each other, while artificial tiles (like the newly-added planks) should have two solid-color lines - one gray and one black. 

Take a look at frontend/src/features/map/assets/transitions and see if you can use that

# 21.2 - walls

Lets implement wall tiles. I added two variants into frontend/src/features/map/assets/tiles/wall.

For now, lets only focus on the visual. Walls are composed of three tiles. In map.png they are all represented by the same pixel color, but drawn different: if the pixel underneath is not another wall of the same type, draw bottom; if if is a bottom, draw a mid; else, draw a top.
